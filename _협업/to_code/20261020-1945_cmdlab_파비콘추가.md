# [cmdlab] 파비콘 추가 (애플 스타일 'C')

- 요청자: Aside
- 승인일: 2026-10-20 (사장님 지시 "'C' 애플스타일로 만들어 추가하자")
- 브랜치 접두어: `design/favicon`
- 세션: CMD-사이트 협업

## 왜
- 사이트에 파비콘이 없어 `/favicon.ico`가 404다. 네이버 서치어드바이저 사이트 진단에 "접근 불가한 페이지 1건(favicon.ico)"으로 잡혀 있다.
- 네이버는 2026-10-15 공지로 파비콘 노출 방식을 바꿨고, 구글도 검색 결과에 파비콘을 표시한다. 지금은 둘 다 기본 아이콘으로 나온다.

## 할 일
1. 이 요청서와 같은 폴더의 `20261020-favicon/` 안 파일 3개를 저장소 **루트로 옮긴다**(`git mv`, 파일 내용 수정 금지).
   - `favicon.ico` (16·32·48px)
   - `icon-192.png` (192px, 둥근 모서리)
   - `apple-touch-icon.png` (180px, 정사각)
2. `index.html`의 `<head>` 안, `<link rel="canonical" ...>` 바로 아래에 아래 3줄을 넣는다.
   ```html
   <link rel="icon" href="/favicon.ico" sizes="48x48">
   <link rel="icon" href="/icon-192.png" type="image/png" sizes="192x192">
   <link rel="apple-touch-icon" href="/apple-touch-icon.png">
   ```
3. `scripts/build-insight.mjs`의 HTML 템플릿 `<head>`에도 같은 3줄을 넣는다(인사이트 목록·글 페이지 공통).
4. `npm ci && npm run build:insight` 실행 후 생성물(`insight/`)을 커밋한다. 생성물 변경은 `<head>`의 3줄 추가만이어야 한다.
5. main 대상 PR 1개. PR 설명에 "머지하면 즉시 라이브" 경고와 아래 자체검증 표.

## 금지
- title, meta description, canonical, robots, JSON-LD, llms.txt, sitemap.xml 내용 변경 금지.
- 기존 URL·파일 이름 변경 금지. 네이버 소유확인 html, IndexNow 키 파일, GA4 태그 유지.
- 아이콘 이미지 다시 만들거나 압축·변환 금지(그대로 이동).
- 요청서에 없는 디자인·문구 변경 금지.
